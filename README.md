## Hi there 👋

Before the age of AI, these were my public repos:

- [zanon.io](https://github.com/diegozanon/zanon.io): my blog v1, built with a custom-made blog engine ([blode](https://github.com/diegozanon/blode)).
- [zanon.dev](https://github.com/diegozanon/zanon.dev): my blog v2, built with another custom-made blog engine and JavaScript framework.
- [bombermon](https://github.com/diegozanon/bombermon): a serverless multiplayer game prototype built to demonstrate the feasibility of using serverless architecture for real-time multiplayer gaming. Developed with the Phaser JavaScript game engine, it explored an innovative approach to gaming infrastructure back in 2016.
- [serverless-notifications](https://github.com/diegozanon/serverless-notifications): a proof of concept for serverless notifications, featuring an innovative implementation for its time (2016).
- [serverless-store](https://github.com/diegozanon/serverless-store): a project developed as a tutorial for [my book](https://www.packtpub.com/en-us/product/building-serverless-web-applications-9781787123076). It showcases how multiple AWS serverless services can be combined to build a website.
